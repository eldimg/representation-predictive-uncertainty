# Рабочие подписи к рисункам и таблицам

Нумерация ниже соответствует английской submission-версии рукописи.

## Рисунок 1 — межмодельное воспроизведение

Средняя разность top-20 entropy на уровне задач между сопоставимыми траекториями
эталонов на естественном языке и Python. Точки показывают среднее по 100 задачам,
интервалы — 99%-е task-bootstrap confidence intervals. Положительное значение
соответствует меньшей предсказательной энтропии Python. Qwen3-4B взят из прямого
запуска Experiment 6; Phi-3 и Mistral — замороженные репликации Experiment 7.
Абсолютные значения энтропии разных токенизаторов не сравниваются.

## Рисунок 2 — профили условий

Средняя top-20 entropy по условиям Experiment 8. Естественно-языковой anchor показан
отдельным ромбом и не соединён с последовательностью изменений представления.
Соединённые точки показывают procedural prose, controlled natural language,
pseudocode, canonical Python и opaque Python. Линии служат только для визуализации
внутри модели и не означают, что абсолютные энтропии разных токенизаторов сравнимы.

## Рисунок 3 — последовательные изменения представления

Контрасты Experiment 8 на уровне задач для трёх семейств моделей. C1 — procedural
prose минус controlled natural language; C2 — controlled natural language минус
pseudocode; C3 — pseudocode минус canonical Python; C4 — opaque Python минус
canonical Python. Точки показывают средние контрасты, интервалы — 99%-е
task-bootstrap confidence intervals. C2–C4 положительны во всех моделях; интервал
Mistral C1 пересекает ноль.

## Рисунок 4 — непрозрачность идентификаторов и эквивалентность

Эффекты C4, определённые как opaque Python минус canonical Python. Точки и интервалы
показывают task-level means и 99%-е bootstrap confidence intervals. Серые области —
заранее определённые model-specific equivalence regions. Все интервалы находятся
выше нуля и соответствующей верхней границы эквивалентности.

## Таблица 1 — воспроизведение NL−Python

Внутримодельные эффекты «естественный язык минус Python» для Experiments 6–7:
99%-е task-bootstrap intervals, positive-task counts и парные стандартизированные
размеры эффекта.

## Таблица 2 — последовательные контрасты

Оценки C1–C4 Experiment 8 по моделям: основные интервалы, sign counts,
valid-vocabulary и semantic-step-balanced robustness effects, а также решения об
эквивалентности C4.

## Таблица 3 — средние по условиям

Описательная средняя top-20 entropy для каждой модели и условия Experiment 8.
Значения предназначены для внутримодельных профилей, но не для прямого ранжирования
абсолютной энтропии между токенизаторами.

## Таблица 4 — устойчивость на уровне семейств

Число семейств с положительным эффектом и описательные диапазоны family-level
effects для основных контрастов Experiments 6–8. Каждое семейство содержит две
связанные задачи и дополняет основной анализ на уровне задач кластерной проверкой.
