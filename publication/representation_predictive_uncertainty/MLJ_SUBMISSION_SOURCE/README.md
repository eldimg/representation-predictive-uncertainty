# Machine Learning submission source package
This directory is a journal-submission staging area, not a change to the frozen experiments.

1. Use `main.tex` with Springer's `sn-jnl.cls` from the official template (https://www.springernature.com/gp/authors/campaigns/latex-author-support).
2. Copy `figure_1_replication_forest.png`, `figure_2_condition_profile.png`, `figure_3_intervention_forest.png`, and `figure_4_c4_equivalence.png` from `../generated/` into **this same directory**, or adapt graphics paths. The journal specifically requests flat LaTeX uploads.
3. Compile `pdflatex main.tex` twice. Inspect typography, table widths, formulas, and bibliography. This is a mechanically converted draft: manual LaTeX validation has NOT been performed.
4. Separate submission attachments are available one folder up: `MLJ_CONTRIBUTION_INFORMATION_SHEET.md`, `MLJ_COVER_LETTER_DRAFT.md`, and `MLJ_SUBMISSION_AUDIT.md`.
5. The bibliography is carried across verbatim in a numbered list, NOT yet final author-year journal-style references. Revise and verify all entries.
6. Source manuscript: `../MANUSCRIPT_MLJ_ADAPTED_EN.md`. Do not claim the PDF is publication-ready until a compiled and visually checked version exists.
7. Verify funding, competing interests, preprint overlap, author affiliation, and AI disclosure before submission.
