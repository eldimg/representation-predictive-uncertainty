# Восстановление provenance модели Qwen в Experiment 6

## Зачем нужен этот документ

В `config.json` завершённого direct-logits запуска Experiment 6 записан
идентификатор `Qwen/Qwen3-4B`, но не сохранена запрошенная или фактически
разрешённая ревизия Hugging Face. Исходный config оставлен без изменений. Здесь
описаны локальные доказательства, по которым ревизия восстановлена без переписывания
исторических метаданных.

## Восстановленная ревизия

```text
1cfa9a7208912126459214e8b04321603b3df60c
```

## Локальные доказательства

Во время аудита каталог кеша Hugging Face `models--Qwen--Qwen3-4B` содержал ровно
один snapshot. Его имя совпадало с указанной ревизией, а `refs/main` содержал тот же
40-символьный commit.

В config Experiment 6 записано:

```text
timestamp_started = 2026-09-16T13:59:37.592534
model_load_seconds = 4.2079471
```

Локальная запись трёх shards весов в единственном snapshot завершилась не позднее
`2026-09-16 13:57:09`, то есть до зафиксированного старта запуска. Следовательно,
этот snapshot уже находился локально, когда `from_pretrained("Qwen/Qwen3-4B")`
разрешал незакреплённый идентификатор.

Контрольные суммы малых файлов snapshot:

| Файл | SHA-256 |
|---|---|
| `config.json` | `8ba006f74fecfaaeb392872a60f4a480e7ec9860153d2e1b769ec81f9a147f8a` |
| `model.safetensors.index.json` | `6dc0981b8829fead746441f68f38f24c5ca4a3a66351f652c26c6df0efc43ab2` |
| `tokenizer_config.json` | `d5d09f07b48c3086c508b30d1c9114bd1189145b74e982a265350c923acd8101` |

Experiment 8 позднее явно загрузил тот же commit и записал разрешённый hash. Размеры
токенизатора и словаря Experiment 6 также соответствуют этому snapshot.

## Доказательная сила

Это сильное локальное свидетельство: кеш содержал единственный snapshot, `main`
указывал на него, а файлы snapshot предшествуют запуску. Однако оно не равно ревизии,
записанной исходным runner во время выполнения, и не является внешней временной
меткой. В статье допустимо сообщить, что ревизия восстановлена из единственного
соответствующего по времени локального cache snapshot. Нельзя утверждать, что её
записал исходный runner.

## Защита будущих запусков

`experiment6_direct_logits/run_direct_hf.py` теперь по умолчанию использует точную
неизменяемую ревизию, передаёт её при загрузке токенизатора и модели, проверяет
разрешённый commit и включает revision fields в resume guard. Новый запуск не может
незаметно перейти на изменившийся `main`.
