# Авторская декларация происхождения корпуса задач

Дата фиксации: 2026-09-24.

## Область декларации

Декларация относится к frozen-корпусу из 100 процедурных задач и 50 семейств,
который хранится в `tasks.json` Experiments 6–8. Для каждой задачи корпус содержит
три natural-language reference solutions и три Python reference solutions.

Пять рабочих копий корпуса побайтно совпадают и имеют SHA-256:

```text
dcdbc196f7dbf394fbf043690c764c470dbbbf9ee333e344c1f62f320a72a164
```

## Кто и как создал корпус

Корпус был создан специально для этого исследовательского проекта с существенным
использованием ChatGPT. Автор проекта определил исследовательский дизайн и
требования:

- 100 процедурных задач;
- 50 различных семейств;
- не более двух задач одного семейства;
- три natural-language reference solutions для каждой задачи;
- три Python reference solutions для каждой задачи;
- последующая заморозка и повторное использование без изменения.

На основании этих требований ChatGPT сгенерировал задачи, их формулировки и
эталонные решения. Исследовательские требования, структура корпуса, число задач и
семейств, критерии эксперимента и решение о замораживании задавались автором
проекта.

В сохранившейся внутренней переписке ChatGPT перед confirmatory Experiment 6
зафиксирован план создать полный пакет «100 задач + три NL + три Python + runner».
Структура созданного `tasks.json` точно соответствует этому плану. Эта переписка
поддерживает восстановленное описание процесса, но не является независимой
публичной временной меткой.

## Время создания

Корпус был создан в середине сентября 2026 года, непосредственно перед
confirmatory Experiment 6, ориентировочно 15–16 сентября. В Git готовый корпус
впервые появился 18 сентября 2026 года в исходном организационном коммите
`4cfeee1e3d3954c211cee68589d90a926e9ad24a`.

Git подтверждает состояние корпуса на момент коммита, но не независимо подтверждает
точный день первоначальной генерации.

## Внешние источники

Конкретные внешние наборы задач, включая LeetCode, HackerRank, HumanEval, MBPP,
учебники и другие опубликованные коллекции, намеренно не использовались и не
адаптировались при составлении корпуса. Задачи генерировались специально для
исследования.

Алгоритмические сюжеты корпуса являются общеупотребительными: поиск, сортировка,
подсчёт, обработка строк, списков, словарей и матриц. Поэтому декларация не
утверждает уникальность самих алгоритмических идей или невозможность случайных
совпадений с другими учебными материалами.

Технический аудит репозитория и выборочный поиск характерных точных формулировок
не обнаружили источник, из которого корпус был бы скопирован как набор. Этот
результат является поддерживающим, но не исчерпывающим доказательством.

Корректная публичная формулировка:

> Корпус был синтетически создан для данного исследования с использованием
> ChatGPT по требованиям автора и не был намеренно составлен из существующего
> внешнего benchmark. Возможные случайные совпадения с общеупотребительными
> учебными задачами независимо не исключены.

## Роль языковой модели

ChatGPT существенно участвовал в:

- создании процедурных задач;
- написании формулировок задач;
- создании трёх natural-language reference solutions;
- создании трёх Python reference solutions;
- подготовке экспериментального кода и процедуры валидации.

Python-решения после генерации проходили автоматическую проверку синтаксической
корректности. В Experiment 8 новые представления исходных задач создавались уже
детерминированными преобразованиями из общего intermediate representation;
использование LLM или внешнего API для генерации этих экспериментальных стимулов
было запрещено.

## Право на публикацию

Автору не известны сторонние материалы, препятствующие публикации корпуса. По
восстановленной истории корпус был создан специально для проекта и не был
намеренно скопирован или адаптирован из стороннего защищённого набора данных.

При создании использовался ChatGPT. Автор указывает, что понимает применимые
условия OpenAI как передающие пользователю права OpenAI на сгенерированный output
в пределах применимого законодательства. Перед публичным релизом актуальную
версию применимых условий следует проверить отдельно. Эта декларация фиксирует
добросовестно восстановленные факты проекта и позицию автора, но не является
независимым юридическим заключением.

## Требования к публичному описанию

Dataset card и README публичного релиза должны сообщать:

1. что корпус синтетически создан специально для исследования;
2. что ChatGPT существенно участвовал в создании задач и reference solutions;
3. какие требования и решения задавались автором проекта;
4. что задачи не являются внешним стандартизированным benchmark;
5. что автоматическая синтаксическая проверка не равна независимой ручной
   проверке всех решений;
6. что независимая проверка стимулов Experiment 8 другим человеком не
   проводилась и это является ограничением исследования;
7. что общеупотребительные алгоритмические сюжеты могут совпадать с другими
   учебными материалами.
